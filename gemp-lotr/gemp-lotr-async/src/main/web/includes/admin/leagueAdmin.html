League schedules i

A schedule creates leagues on its own: the same settings, an ordered rotation of events, and a cadence. Each league is created a few days before it starts so players can sign up. Nothing is created while a league with the same name is still active.

Collection i
"All cards" lets players build from every card in the game; "My cards" restricts them to the cards they own.
Campaign i
Leagues that share a campaign tag belong together: a participation prize can then count the games a player has played across all of them, and is handed out once per campaign. Leave blank for a stand-alone league.
Prizes i
Extra prizes handed out when the league ends, on top of the automatic ones. Each tier says who qualifies (a range of final places, ties included, or a minimum number of games played) and what they get. An item is a card or pack id (9_1 is set 9 card 1; add * for foil or T for tengwar) or, when the card does not exist yet, "to be announced" with a description: players receive a placeholder card that is swapped for the real one once it is resolved on the Prizes tab.
Format i
Each serie runs for the given number of days, one after the other, and only the first "max matches" ranked games count per player. Sealed and Draft leagues take one entry; Constructed and Race to Mount Doom can chain several formats.
Race configuration i
Players advance along a path of meta-sites, each carrying a modifier card. Set the path length and intensity range, press Randomize (locked sites are kept), or add modifiers by hand. Drag sites to reorder; right-click a card to preview it.

League name pattern i
How each created league is named. Tokens: {series} the series name, {event} the event name, {month} September, {mon} Sep, {mm} 09, {year} 2026, {yy} 26. The result must be 45 characters or less.
Repeat every i
Whole months keep the day of the month (the 1st stays the 1st). 0.25 = weekly, 0.5 = every two weeks, 1.5 = a month and two weeks.
