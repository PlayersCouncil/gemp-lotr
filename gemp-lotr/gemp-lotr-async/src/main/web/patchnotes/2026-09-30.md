summary: Adding support for King Standard Sealed.  Small tweaks to UX update features.
tags: Sealed
---

- Added support for King Standard Sealed, a new event which will be ran in the near future.
- The Connection status in the main hall will now show "Shutdown" when the server has been put into shutdown mode pending a new deployment.
- Added support for twilight symbols in patch notes and other markdown-aware systems on Gemp.
- Fixed the Play window automatically switching the deck you selected if you switched to a different format other than what the deck targets; now after you select a deck it will not update that dropdown for you again for that session.
- Fixed greyed-out cards stacked on another card (such as**[[Library of Orthanc]]**) visually appearing to not be selectable when they actually are. ([#1104](https://github.com/PlayersCouncil/gemp-lotr/issues/1104))
